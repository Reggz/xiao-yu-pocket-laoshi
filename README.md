# Xiao Yu (小语) — Pocket Lao Shi

Mandarin practice bot for English speakers. Text-first, level-gated, and topic-aware.

## Repo Layout
- docs: product and architecture documents
- src: application source

## Getting Started
- Requirements: Node.js 18+
- Copy .env.example to .env and fill in:
  - TELEGRAM_BOT_TOKEN
  - DATABASE_URL
  - LLM_API_KEY (optional)
