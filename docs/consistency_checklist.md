# Consistency Checklist

Use this after each phase:

1. PRD alignment
- Are new features reflected in docs/PRD.md?

2. Architecture alignment
- Are new components reflected in docs/architecture.md?

3. Data Model alignment
- Are required fields reflected in docs/data_model.md?

4. Interaction Rules
- Are behavior rules updated in docs/interaction_rules.md?

5. Tests
- Are there unit tests? Do they pass?

6. Progress tracking
- Update docs/progress.md

7. Project Memory
- Add key decisions if new rules were introduced
